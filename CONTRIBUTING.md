# Contributing to Kura

Thank you for helping improve Kura.

## Development setup

1. Install Node.js 20 or newer.
2. Clone this repository.
3. Run `npm test`.
4. Test the CLI with `node bin/kr.mjs --version` and `node bin/kr.mjs doctor`.

## Pull requests

- Keep each pull request focused on one problem.
- Add or update tests for behavior changes.
- Document new syntax, CLI commands, targets, and diagnostics.
- Avoid committing generated build outputs, credentials, or private data.
- By submitting a contribution, you agree that it may be distributed under the repository's MIT OR Apache-2.0 dual license.

## Commit style

Use short imperative summaries, for example: `Improve parser recovery`.
