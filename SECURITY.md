# Security Policy

## Supported version

Security fixes currently target Kura v1.x.

## Reporting a vulnerability

Do not publish exploitable details in a public issue. Contact the repository owner privately through GitHub and include:

- affected version and platform
- reproduction steps or proof of concept
- expected impact
- suggested remediation, when available

Reports should not include secrets, access tokens, personal data, or attacks against systems you do not own or have permission to test.
